# Customer Support Operations & SLA Performance Analysis

## 📌 Project Overview

This project analyzes **1,000 customer support tickets** to evaluate operational performance, service-level compliance, resolution efficiency, customer satisfaction, and support-channel trends.

The analysis was performed using **Microsoft Excel**, with a focus on data cleaning, validation, operational KPI analysis, PivotTables, PivotCharts, and dashboard development.

The goal of the project is to identify operational patterns, SLA issues, and areas where support processes could be improved.

## 📊 Dataset

The dataset contains **1,000 customer support tickets** with information including:

* Ticket ID
* Created Date
* Customer ID
* Support Channel
* Priority
* Category
* First Response Time
* Resolution Time
* Ticket Status
* Customer Satisfaction

Missing values were retained where appropriate, particularly for unresolved tickets and satisfaction ratings.

---

## 🧹 Data Cleaning & Preparation

The following data preparation steps were performed:

* Reviewed the dataset for missing and inconsistent values.
* Converted ticket creation timestamps into usable dates.
* Converted response and resolution times from minutes into hours.
* Created derived operational metrics using Excel formulas.
* Categorized tickets based on SLA performance.
* Classified tickets as resolved or unresolved.
* Categorized customer satisfaction ratings.
* Created month-level fields for trend analysis.

## ⏱️ SLA Analysis

For this project, the following SLA thresholds were used as **analytical assumptions**:

| Priority | SLA Threshold |
| -------- | ------------: |
| Urgent   |       8 hours |
| High     |      24 hours |
| Normal   |      48 hours |
| Low      |      72 hours |

The analysis identified **179 tickets that breached the defined SLA thresholds**.

SLA performance was analyzed across different priority levels to identify areas requiring operational attention.

---

## 🔎 Key Insights

* **83.5%** of tickets were resolved, while **16.5%** remained unresolved.
* Overall SLA compliance was **78.6%**.
* **Normal-priority tickets** had the highest volume with **405 tickets**.
* **Low-priority tickets** recorded the highest number of SLA breaches with **96 breaches**.
* Average resolution time was **33.6 hours**.
* Average customer satisfaction was **2.97 out of 4**.
* Monthly ticket volume was analyzed to identify changes in operational workload over time.
